# Media Watcher

## Описание

**Media Watcher**
- Непрерывно обходит файловую систему
- Классифицирует файлы по категориям на основе расширений (конфигурируется через YAML)
- Предоставляет REST API для доступа к информации о файлах
- Сохраняет данные в формате JSON

### Требования

- **CMake** версии 3.16 или выше

### Сборка

```bash
git clone <URL_репозитория>
cd media_watcher
mkdir build && cd build
cmake ..
make
cd ..
```

### Запуск

Приложение принимает 4 параметра из командной строки:

```bash
./build/media_watcher <path> <interval_ms> <enable_server> <enable_file_saving>
```

**Параметры:**
- `<path>` — путь к директории для обхода
- `<interval_ms>` — интервал сканирования в миллисекундах
- `<enable_server>` — включить HTTP сервер (0 или 1)
- `<enable_file_saving>` — включить сохранение в файл (0 или 1)

**Примеры запуска:**

```bash
# Мониторить домашнюю директорию с интервалом 2000мс, сервер отключен, запись включена
./build/media_watcher $HOME 2000 0 1

# Мониторить текущую директорию с интервалом 5000мс, сервер включен, запись отключена
./build/media_watcher . 5000 1 0

# Мониторить /tmp с интервалом 10000мс, оба параметра включены
./build/media_watcher /tmp 10000 1 1
```

**Значения по умолчанию** (если параметры не указаны):
- Путь: `$HOME` (домашняя директория)
- Интервал: `10000` мс
- Сервер: отключен (`0`)
- Сохранение: включено (`1`)

### Конфигурация

Перед запуском создайте файл конфигурации `configs/extensions.yaml` для определения категорий файлов:

**Пример файла configs/extensions.yaml**
```yaml 
Images:
  - jpg
  - jpeg
  - png

Audio:
  - mp3
  - wav
  - flac
  - aac

Video:
  - mp4
  - mov
  - webm
```

##  Используемые библиотеки

| Библиотека | Версия | Назначение |
|-----------|--------|-----------|
| **nlohmann/json** | v3.11.3 | Работа с JSON форматом для сохранения и передачи данных |
| **yaml-cpp** | v0.9.0 | Парсинг конфигурационных файлов в формате YAML |
| **bshoshany_thread_pool** | v5.1.0 | Пулл потоков |
| **cpp-httplib** | v0.18.3 | Встроенный HTTP сервер для REST API |

Все зависимости автоматически загружаются и компилируются через CMake FetchContent.


## Основные функции

**Рекурсивный обход заданной директории с помощью поставновки задачи на обход в пул потоков**


## Как это работает

При запуске приложение:
1. Читает конфигурацию из `configs/extensions.yaml`
2. Выводит загруженные расширения по категориям
3. Показывает текущие параметры запуска
4. Начинает сканирование указанной директории
5. Периодически проверяет изменения в файловой системе с заданным интервалом
6. (Опционально) Сохраняет результаты в JSON файл
7. (Опционально) Запускает HTTP сервер для доступа к данным

**Пример вывода при запуске:**
```
Loaded extensions:
Images: jpg jpeg png gif bmp webp 
Documents: pdf doc docx txt xls xlsx 
Audio: mp3 wav flac aac 
Video: mp4 avi mkv mov webm 

Settings:
Path: /Users/username
Time interval: 2000
Saver: 0
File saving: 1
```

### Получение данных через API
После запуска с включенным сервером (`enable_server 1`) вы можете получить информацию о файлах через HTTP запрос к localhost:1234/media_files.

**Пример запроса:**
```bash
curl http://localhost:1234/media_files
```

**Пример ответа:**
```json
{
    "Images": [
        "photo.jpg",
        "screenshot.png",
        "wallpaper.webp"
    ],
    "Documents": [
        "report.pdf",
        "notes.txt",
        "spreadsheet.xlsx"
    ],
    "Audio": [
        "music.mp3",
        "podcast.wav"
    ],
    "Video": [
        "movie.mp4",
        "tutorial.mkv"
    ]
}
```
